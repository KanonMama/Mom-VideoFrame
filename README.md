# Mom Video Frame v1.3.1

Видеорамка для SillyTavern: встроенный YouTube/Vimeo, отдельная громкость, очередь и шесть тем. Для воспроизведения нужен доступ к видеосервисам, но собственный сервер расширению не нужен.

## Установка из GitHub (рекомендуется)

1. Загрузи файлы `manifest.json`, `index.js`, `style.css`, `README.md` **в корень репозитория** (не в подпапку `Mom-VideoFrame`).
2. В SillyTavern открой **Расширения → Установить расширение**, вставь адрес репозитория GitHub и выбери установку для своего пользователя.
3. Обновлять Git-установку можно через **Расширения → Управление расширениями → Обновить**. Для автоматических проверок обновлений `auto_update` включён в `manifest.json`; дополнительно это зависит от настроек SillyTavern.
4. Перед установкой из GitHub удали старые **локальные** копии в `public/scripts/extensions/third-party/Mom-VideoFrame` и `data/<user>/extensions/Mom-VideoFrame`, чтобы не получить дубликаты. Настройки интерфейса остаются в localStorage браузера.

## Ручная установка

1. Распакуй ZIP.
2. Папку **Mom-VideoFrame** (не сам ZIP и не её содержимое по отдельности) положи сюда:

   `SillyTavern/public/scripts/extensions/third-party/Mom-VideoFrame/`

   Если SillyTavern в твоей сборке хранит расширения в `data/<пользователь>/extensions`, можно положить туда.
3. Перезапусти SillyTavern или обнови её вкладку с полным перезагрузом.

Ничего устанавливать через меню GitHub не нужно. На диске должны лежать три файла:

- `manifest.json`
- `index.js`
- `style.css`

## Обновление с v1.0.0 или v1.1.0

Замени файлы в уже установленной папке `Mom-VideoFrame` содержимым папки из нового ZIP. Не создавай вложенную папку `Mom-VideoFrame/Mom-VideoFrame`. Настройки, положение, выбранная тема и ссылки сохраняются в браузере и останутся прежними. После замены обнови вкладку SillyTavern (лучше Ctrl+F5).

## Диагностика обновления в 1.2.1

- В окне настроек внизу показывается строка с текущей версией (например, **Mom Video Frame · v1.3.1**). Она не зависит от выбранной темы, и по ней видно, какая версия действительно запущена.
- Если раздел **MOM VIDEO FRAME** появился среди настроек расширений, в его заголовке тоже показывается номер текущей версии.
- CSS загружается с отдельным адресом с номером текущей версии, чтобы не использовать старое оформление из кэша.
- **Настройки не сбрасываются:** ключ localStorage остался прежним, сохранённые размеры, положение, тема и ссылка остаются.

Если после замены надписи v1.2.1 нет, это означает, что SillyTavern загрузила другую копию файлов или старый JS. Проверь наличие двух папок `Mom-VideoFrame` (в `public/scripts/extensions/third-party` и `data/<user>/extensions`) и отсутствие случайной вложенности `Mom-VideoFrame/Mom-VideoFrame`.

## Новое в 1.2.0

- Шестая тема **«Под тему ST»**: фон корпуса, текст, линии и акцент берутся из активных CSS-переменных темы SillyTavern (`SmartTheme*`), а шрифт — из `--mainFontFamily`, если он задан. Переключение темы ST обновляет цвета рамки без перезагрузки и без отдельной синхронизации.
- Темы диспетчерской, ЭЛТ, VHS, метро и ночная остались без изменений.
- Улучшена регистрация раздела в настройках расширений при поздней загрузке панели ST.

## Изменения 1.1.0

- **🔒 / 🔓 в верхней панели плеера** — заблокировать / разблокировать мышь поверх видео. Когда заблокировано, прозрачный слой перехватывает наведение и клики, поэтому YouTube не показывает подсказки и управление от движения мыши. Это не управление интерфейсом самого YouTube: его служебные элементы при загрузке или паузе могут появляться сами.
- В списке **Расширения** SillyTavern появился сворачиваемый блок **MOM VIDEO FRAME** с выключателем всей рамки (включая кнопку возврата), галочкой блокировки видео и кнопкой быстрого вызова настроек.
- Чтобы было возможно включить или запустить новое видео, каждое нажатие **ОТКРЫТЬ** автоматически снимает блокировку. После запуска поставь замок.
- После полного выключения из меню расширений видео останавливается. Повторно включить можно там же.

## Управление

- **Перемещать**: за верхнюю панель рамки.
- **Размер**: за правый нижний угол (◢). Можно и стрелками с клавиатуры, когда угол выбран.
- **⚙**: открыть настройки, сменить один из шести корпусов, надпись и толщину рамки.
- **▣ / ▶**: быстро переключить режимы внешнего окна и встроенного плеера.
- **×**: спрятать рамку. Вернуть — кнопка «ВИДЕОРАМКА» справа внизу.
- **Сброс положения**: в настройках. Изменения сохраняются в localStorage этого браузера.

## Режимы

**Внешнее окно**: центральная часть рамки прозрачна. Перетащи поверх неё обычное окно видео или браузерное Picture-in-Picture и подгони рамку под его размер. Важно: видео не является частью этой рамки, и отдельное окно всегда может оказаться поверх неё. Сделай рамку немного больше окна, чтобы края были видны.

**Плеер по ссылке**: работает с YouTube (обычные ссылки, youtu.be, Shorts, прямые трансляции, плейлисты), Vimeo, прямыми ссылками на MP4, WebM, OGG. Встройка зависит от разрешений и ограничений владельца ролика, сайта и браузера. Видео загружается **только после нажатия «Открыть»**, а при скрытии рамки останавливается.

## Приватность и совместимость

- Расширение не читает чаты, ключи, модели, персонажей, настройки API и т.п.
- Не обращается к моделям или чатам. Сеть используется только после запуска видео: для медиаплеера и, для YouTube, загрузки официального IFrame API.
- Сохраняет положение, оформление, режим, список ссылок и громкость локально в `localStorage` текущего браузера.
- Shadow DOM изолирует оформление от тем SillyTavern и других расширений.
- Проверка структуры и синтаксиса выполнена; работа в конкретной сборке ST зависит от версии и модификаций.

### Удаление

Удалить папку `Mom-VideoFrame` и перезагрузить ST. Чтобы стереть сохранённые настройки, удалить ключ `mom-video-frame:v1` из Local Storage сайта SillyTavern через инструменты разработчика браузера.

## Обновление 1.3.0 — громкость и очередь

- Значок `♫` в верхней панели открывает ползунок громкости и кнопку выключения звука. Ползунок доступен даже при включённой блокировке видео. Значение сохраняется локально. Для YouTube нужен официальный YouTube IFrame API: при блокировке этого API внешняя громкость и автопереход недоступны, хотя видео может продолжать воспроизводиться.
- В настройках сохранилась одиночная ссылка с «Открыть» — она заменяет очередь одним роликом. Новый блок «Очередь воспроизведения» принимает несколько ссылок, по одной на строке, и позволяет переставить, удалить или вручную запустить любую из них (до 60 ссылок).
- Кнопки «предыдущее» / «следующее» доступны в заголовке при наличии минимум двух ссылок. Очередь и громкость сохраняются между перезагрузками, но само воспроизведение после перезагрузки не запускается.
- Автопереход по окончании видео реализован для YouTube и для прямых .mp4/.webm/.ogg. Vimeo требует ручного перехода. Браузер может ограничить автоматический запуск следующего ролика.
- Внешний декоративный режим управлять чужим отдельным окном не может.

При обновлении замените файлы единственной установленной копии `Mom-VideoFrame` (не оставляйте дубли в `public` и `data/default-user/extensions`). Версия в настройках сборки для GitHub — `v1.3.1`.

## Сборка v1.3.1 для GitHub

Функциональность плеера соответствует v1.3.0. Включён параметр `auto_update` в манифесте и обновлена отображаемая версия.
